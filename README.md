# 2026 国庆鄂西—湘西自驾计划

一份适合手机查看、桌面浏览和打印保存的单页行程网页。

## 行程摘要

- 日期：2026 年 9 月 30 日至 10 月 7 日
- 出发：9 月 30 日 14:00 从武汉出发，正常路况约 18:00 抵达宜昌
- 路线：武汉 → 宜昌 → G348 → 芝茅公路 → 秭归 → 木鱼 → 神农顶 → 大九湖 → 三峡之巅 → 八面山 → 醴陵 → 武汉
- 规划里程：约 2330 公里
- 住宿：宜昌、秭归、木鱼、坪阡、兴隆镇、八面山、醴陵
- 已确认住宿：9 月 30 日丽橙酒店·智（宜昌火车东站五一广场店）¥220/间，2 间合计 ¥440；10 月 1 日秭归若兮酒店 ¥399/间，2 间合计 ¥798；已确认住宿合计 ¥1,238
- 记账单：当前攻略页内嵌腾讯文档在线账单，4 个人打开同一个页面即可查看和编辑最新记录

## 本地预览

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000`。

## 校验

```bash
node scripts/validate.mjs
```

## 发布

仓库从 `main` 分支根目录发布 GitHub Pages。页面为纯静态文件，不依赖构建工具或外部 CDN。

## 在线账单

账单使用腾讯文档在线表格，页面通过内嵌方式显示。需要修改账单时，直接在页面中的表格内编辑即可；如果内嵌区域没有显示，可点击表格上方的“在腾讯文档中打开”。

## 提醒

页面中的里程和时间是规划值。出发前 48 小时应重新核对天气、实时导航、道路施工、景区预约和临时交通管制。
